## 5. 조사하면서 정리된 것

**정책 데이터에 필요한 칸** (위 정책들을 다 담으려면)
1. `id`, `name`, `area`(주거/출산/연금/일자리/돌봄), `summary`
2. `status`: 현행 / 과거 한시 / 논의 중
3. `eligibility`: 조건식 (예: `age <= 34 && own_home == 0`)
4. `effects`: 세 종류가 필요함
   - **매년 지급** (아동수당, 월세 지원): 조건이 맞는 동안 해마다 금액
   - **사건 때 한 번** (첫만남이용권, 부모급여 첫해): 출산·결혼·취업 같은 사건에 붙음
   - **수치 바꾸기** (연금 보험료율, 대출 금리·한도): 시나리오 수치를 덮어씀
5. `duration`: 개인 기준(월세 2년, 장려금 2년)과 정책 기준(특례 1년) 두 가지
6. `history`: 실제 도입·변경 연도 → 랜덤 정책 이벤트를 만들 때 "어떤 식으로 바뀌어 왔는지"의 근거
7. `sources`: 제목, URL, 확인 날짜

**엔진에 새로 필요한 것**
- **실업 상태** (구직급여를 쓰려면)
- **아이 나이** 추적 (부모급여 0~1세, 아동수당 9세 미만 → 13세 미만)
- **연도별 수치** (연금 보험료율이 2026~2033년에 해마다 오름)
- 난수를 **개인의 운**과 **나라의 운**(정책 등장)으로 나누기

**확인이 더 필요한 수치**
- 신생아 특례 대출의 현재 금리
- 장기요양 시설급여 본인부담률
- 청년월세 지원 소득 기준의 실제 금액 (중위소득 60%가 얼마인지)
